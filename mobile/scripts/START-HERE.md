# Maslul emulator test: start here

1. Read **`TESTING.md`** and follow it from top to bottom in one go. It is the only set of instructions.
2. Install **`maslul-latest.apk`** (the app under test). The two `maslul-kotlin-*.apk` files are old versions, not used this round.
3. Write your report in **`report.md`** and put every screenshot and log in **`evidence/`**.
4. Ignore **`archive/`**: earlier rounds, out of date.

Do everything yourself; don't ask the human to tap or check anything. A failure is a finding: record it and go on.
